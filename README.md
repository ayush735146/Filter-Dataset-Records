# Veda Technology - Task 19
## Filter Dataset Records

This project demonstrates how to filter records from a Pandas DataFrame using Boolean conditions.

### Tools
- Python
- Pandas
- Jupyter Notebook

### Filtering examples
1. Marks greater than 80
2. Students from Mathura
3. Marks greater than or equal to 80 AND age below 22

### Key concepts
- Boolean indexing
- `&` for AND
- Parentheses for multiple conditions
- `len()` to count filtered records

### Run
```bash
pip install -r requirements.txt
python filter_dataset_records.py
```
